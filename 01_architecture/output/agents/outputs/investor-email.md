# Investor Email

The blast that goes to the broker's list the day the deal hits the market.
Read on phones, skimmed in 10 seconds, judged on the subject line.

## Subject lines (produce 3 options)

Write them like a person emailing a colleague, not like a listing flyer.

1. **Numbers-forward:** e.g. "29-unit multifamily in SW Portland at a 4.67% cap"
2. **Upside-forward:** leads with the strongest highlight (only if the underlying number is in deal-facts)
3. **Process-forward:** deadline/call-for-offers framing, if an offer deadline exists

Deliverability rules — spam filters punish all of these:

- ≤ 55 characters each.
- **No separator characters**: no "|", "•", "·", "—", "/" between phrases.
  Use natural phrasing or a single comma instead.
- No bracketed tags like [NEW LISTING], no all-caps words, no exclamation
  points, no emoji.

## Body

- **Opening line** — the deal in one sentence. No "I hope this email finds you well."
- **Stat block** — 4–6 lines, `label: value`, one per line: price/guidance, units, cap rate, occupancy, NOI, price/unit. Skip missing ones.
- **Two sentences of narrative** — the strongest highlight, then the process (deadline, OM available on request).
- **Signature** — broker contact block from deal-facts.

## Rules

- ≤ 150 words body. Every sentence must survive "would the broker cut
  this?".
- Plain-text-first: the HTML variant is the same content with the stat
  block as a simple table — no images except an optional hero photo at
  bottom, so deliverability isn't image-gated.
