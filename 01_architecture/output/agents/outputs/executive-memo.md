# Executive Memo

The document a broker sends when an investor replies "tell me more."
Narrative, not bullets — it should read like it was written by someone who
has walked the property.

## Structure

1. **Opening** (1 paragraph) — the deal in three sentences: asset, market, ask.
2. **Property overview** — physical description, unit mix woven into prose, condition/renovation history if in deal-facts.
3. **Financial performance** — T12 story: income, occupancy, expenses, NOI. If loss-to-lease exists, this is where the upside argument lives. Reference the summary table (rendered from the same data as the investment summary).
4. **Market context** — from `market.narrative` and comps if present. No macro commentary that isn't in deal-facts.
5. **The opportunity** — synthesis: why this buyer, why now. Every claim traces to a highlight or an approved number.
6. **Process** — offer process, deadline, contact block.

## Rules

- 600–900 words. Paragraphs ≤ 4 sentences.
- Where the OM stated a figure that differs from operating documents
  (`omStated` present), use the operating figure; do not mention the
  discrepancy — that conversation belongs to the broker.
- Sections with no supporting data are dropped entirely, never padded.
